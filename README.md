# 开屏跳过 · SplashSkip

跳过开屏广告的软件。这几天被一些软件的广告折磨烦了，一些课程软件这些每天都在用的动不动弹广告手没怎么动就跳进广告了，在GITHUB上找了几个相关软件用发现有些还是不能跳过，于是自己做了一个改了几版，试了一下他们不能跳过的可以跳过了，主要用 Android 无障碍服务识别并点击开屏广告的跳过按钮。支持 **Android 8.0 及以上**，免 Root。规则和处理记录都保存在手机本机。

测试了一些软件包括课程、营业厅、视频、快递等软件，都能跳过广告。

最重要的一点，记得把想跳过的软件加入到加强跳过里，标准跳过的识别规则比较严格，可能会漏掉比较多的广告；加强跳过我测试的几个软件都成功了。若各位还有失败的案例可以反馈给我，尽量包括跳过失败的广告图片，我继续修改。若该软件对你有帮助请给我一个免费的STAR，谢谢各位！

## 安装与使用

1. 从 Release 页下载 `SplashSkip-版本号.apk` 并安装。已有同签名版本时，可覆盖安装并保留设置。
2. 打开「开屏跳过」，从首页进入系统无障碍设置，若第一次不能开启无障碍，请在设置-应用-权限-右上角更多关闭限制后续即可开启此软件无障碍，启用同名服务。返回后确认首页显示「运行中」。
3. 在「应用」里选择目标 App 和跳过模式，点「保存并试用」。也可以保存后从桌面正常打开目标 App。
4. 最长等 12 秒，到「记录」查看这次的试用诊断。遇到误点，可以在记录里直接停用对应 App 的跳过。

5.建议把该软件后台锁住，以免反复开关。

Android 13 及以上的部分设备会限制侧载应用开启无障碍。如果开关置灰，首页会提供对应帮助入口。仅在确认信任安装包时，按系统提示允许受限制的设置。[Android 帮助](https://support.google.com/android/answer/12623953?hl=zh-Hans)
